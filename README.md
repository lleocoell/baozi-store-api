# Baozi Store - Desenvolvimento Web Back-End

Este projeto foi desenvolvido para a atividade prática da disciplina de Desenvolvimento Web Back-End da UNINTER.

O objetivo é criar uma API REST para uma loja chamada Baozi Store, permitindo o cadastro e a consulta de clientes, produtos e pedidos.

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Data JPA
- Banco de dados H2
- Postman para testar as requisições

## Funcionalidades

O sistema permite cadastrar, listar, buscar por ID e excluir clientes, produtos e pedidos. Também foi implementada a atualização de produtos.

## Testes realizados

Utilizei o Postman para testar os endpoints da API, usando os métodos POST, GET, PUT e DELETE.

Os testes realizados apresentaram respostas de sucesso, como 200 OK e 204 No Content.
